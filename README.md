# Đừng Để Tiền Rơi - Stock Market Edition

Web game based on the GDD Rev03.
Built with Next.js (App Router), Tailwind CSS.

## Getting Started

1. `npm install`
2. `npm run dev`
3. Open [http://localhost:3000](http://localhost:3000)

## Deploy to Vercel
Push this repository to GitHub and connect it to Vercel for immediate deployment.
